A tiny program that writes one roast of a smart fridge to /output/entry.txt: it has a camera, an app, and strong opinions about the milk, but ask it to make ice and suddenly it is a minimalist. Deterministic, no network, no dependencies.

## Run it

```sh
python3 main.py
```
